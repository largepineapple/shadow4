# 需求

创作者提供主题、受众、平台、目标时长、风格，基于合成素材和品牌规则获得可编辑脚本：标题、分镜、旁白/字幕、预计总时长、来源ID、风险与任务状态。

五类强制验收：正常生成、缺关键信息、无素材、工具失败、超时长修正或明确无法满足。扩展包括规则失败修订、改变时长、改变/清空素材、瞬时故障恢复、编辑后检查失效与执行上限。

模型根据工具观察决定改写查询、请求补充、生成新草稿、压缩/修订、再次检查或停止。不得无依据添加效果数据，不得把工具调用成功等同于检查通过。仅通过同一候选的时长与规则检查才能completed。

目标为时长上限，不要求精确填满；全部素材/品牌词表为合成。可选initial_draft支持编辑工作流，其来源必须如实说明，不能把用户给定草稿冒称模型生成。
